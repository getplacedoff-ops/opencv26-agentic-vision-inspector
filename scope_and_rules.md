# Stage 1: Ingest & Scope — OpenCV AI Competition 2026, powered by AWS

- **Platform**: Devpost ([https://opencv26.devpost.com/](https://opencv26.devpost.com/))
- **Sponsor / Administrator**: Amazon Web Services (AWS) & OpenCV Foundation
- **Final Submission Deadline**: October 26, 2026 @ 11:45 PM PDT (`2026-10-27T06:45:00Z`)
- **Total Prize Pool**: $20,250 ($5,000 1st, $3,000 2nd, $2,000 3rd, $1,000 Best Use of COOL Award, $1,000 Agentic Vision Award, 55x $150 AWS Compute Grants)
- **Judging Criteria**:
  1. Technical Execution (30%): Correctness and depth of the OpenCV implementation
  2. Innovation (20%): Originality and thoughtful use of computer vision or AI
  3. Real-World Impact (20%): Importance of the problem, usefulness, and evidence of benefit
  4. User Experience (10%): Usability, accessibility, and quality of interaction
  5. Documentation & Presentation (10%): Clarity of report, code, architecture, instructions
  6. Cloud Delivery, Reproducibility & Responsible Operation (10%): AWS deployment quality, repeatability, observability
- **Featured Focus Tracks Targeted**:
  - **Agentic Vision with OpenCV**: Multi-step perception-decision-action loop where OpenCV visual measurements dynamically modify subsequent tool calls, preprocessing parameters, and operational actions.
  - **Cloud-Optimized Vision with COOL on AWS Graviton**: Reproducible latency/throughput benchmarks and hybrid x86/Arm container deployment architecture.
